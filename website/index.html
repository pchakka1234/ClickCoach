SHOW ME. GUIDE ME. LET ME TRY.

A little help, on your terms.

◎

Show me.

A ring and arrow point to a matching visible control. You move the mouse and make the click. Ambiguous targets stay unmarked.

▶

Read it aloud.

Hear the current instruction with a local system voice. Stop, replay, or change the speed—without an extra Gemini request.

↗

Let me try.

Hide the detailed instruction and attempt the step yourself. Choose “Give me a hint” whenever you want guidance.

AI guidance can be imperfect. Check each step before acting. Highlights work on supported, visible page controls; they may be unavailable in embedded or canvas-based interfaces.

DEVELOPER PREVIEW
  1. Get the extension build.

    Ask the project team for the configured client/dist folder, or build it from the project with cd client and npm run build after environment setup.

  2. Load it in Chrome.

    Open chrome://extensions, enable Developer mode, choose Load unpacked, and select the dist folder.

  3. Pin it. Open it. Try it.

    Pin ClickCoach from Chrome’s extensions menu. Open a normal web page, click the extension, and sign in. Enter your goal and capture the tab to start.

A few things to know.

Is it watching my screen all the time?

No. ClickCoach captures the visible tab only when you press the screenshot button. You can review or remove that capture before sending it.

Where does my information go?

Your goal, page title, URL, visible control labels and roles, and optional screenshot go to the configured server and AI provider. Guides, progress, and conversation text are saved in Supabase. The app does not store screenshot images. Hide private information before capturing.

Does narration use Gemini credits?

No. Read aloud uses a local system voice to speak existing instructions. Voice availability varies by device; the extension will let you know if no local voice is available.

Does Show me click for me?

No. It draws a highlight over a uniquely matching visible control. You stay in control of every action. Click the control, press Escape, or choose Hide highlight to dismiss it.

Do I need a Gemini API key?

The project operator configures the Gemini key on the backend. It does not belong in this website or a distributed extension. A working backend and Supabase configuration are required for this preview.

Is it available in the Chrome Web Store?

This page provides manual installation instructions for the hackathon build. A Chrome Web Store listing is not linked yet.
